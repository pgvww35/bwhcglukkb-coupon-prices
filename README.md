## 常见问题

**BWHCGLUKKB 可以和新用户注册优惠叠加吗？**
搬瓦工的折扣码体系一次只能使用一个码，不存在叠加，结账时填一个即可。

**续费时价格会变吗？**
循环优惠码的意义就在于续费同价同折。如果购买时用的是某个循环码，续费时该折扣仍然生效；如果购买时没有任何折扣，续费也按原价走。

**套餐买错了能换吗？**
搬瓦工支持套餐间迁移（同一系列内切换机房、跨套餐升级都有对应通道），具体规则在 KiwiVM 面板里操作，不用销毁重买。

**支持什么付款方式？**
支付宝、微信支付、PayPal、信用卡都支持，国内用户用支付宝扫码即可完成。

**KVM 40G 那种半年付和年付差多少？**
KVM 40G 半年付 $52.99、年付 $99.99，年付相当于每个月便宜约 $1，长期使用选年付更划算。
